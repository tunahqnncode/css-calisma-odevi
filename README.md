Bu proje, [Frontend Mentor](https://www.frontendmentor.io) üzerindeki [Base Apparel coming soon page challenge](https://www.frontendmentor.io/challenges/base-apparel-coming-soon-page-5d46747a0db4a100157f751e)'ının çözümüdür.

## Özellikler

- Masaüstü ve mobil ekranlar için tam uyumlu (Responsive) tasarım.
- Flexbox ile iki sütunlu modern yerleşim yapısı.
- Şeffaf form elemanları ve özel tasarım butonlar.
- Orijinal tipografiye uygun Google Fonts entegrasyonu (`Josefin Sans`).

## Kullanılan Teknolojiler

- HTML5
- CSS3
